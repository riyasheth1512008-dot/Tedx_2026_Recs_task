# TEDxNITKSurathkal Landing Page

A creative, responsive front page recreated for **TEDxNITKSurathkal**, featuring TEDx's signature red, black, and white design language.

## Features
- **Signature Styling:** Dark theme paired with TEDx red accents (`#e62b1e`).
- **Responsive Design:** Mobile and desktop friendly layouts.
- **Smooth Animations:** Interactive scroll reveals on speaker cards and schedule timelines.
- **Clean Sectioning:** Hero section, About info, Speaker roster, Timeline schedule, and Footer.

## Setup & Run Instructions
1. **Clone the Repository:**
   ```bash
   git clone [https://github.com/YOUR_GITHUB_USERNAME/Tedx_2026_Recs_task.git](https://github.com/YOUR_GITHUB_USERNAME/Tedx_2026_Recs_task.git)
   ```
2. **Open the Webpage:**
   Open `index.html` in any web browser (or use VS Code's **Live Server** extension for real-time previewing).

## Project Structure
- `index.html` — Main HTML document
- `styles.css` — Custom CSS stylesheet & responsive layouts
- `script.js` — Lightweight interaction and scroll animation script
